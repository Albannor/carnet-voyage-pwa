# Persistance

Ce répertoire contient le dépôt IndexedDB indépendant de React, ses modèles de stockage et ses erreurs structurées. La base version 1 sépare métadonnées, contenu normalisé, ressources passives et futurs états personnels.

Les décisions, clés, transactions et limites sont décrites dans [`docs/PERSISTENCE.md`](../../docs/PERSISTENCE.md).
